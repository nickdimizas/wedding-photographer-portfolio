# Stratos Zografos | Fine Art & Architectural Portfolio

A premium, high-end editorial portfolio application built for Athens-based fine art and commercial photographer Stratos Zografos. This platform is meticulously engineered to bridge the gap between heavy, high-resolution media assets and elite web performance, offering an immersive, boutique gallery experience across all modern viewports.

---

## 🛠 Architectural Tech Stack

*   **Semantic HTML5:** Built using rigorous accessible milestones to maximize SEO crawlability, document hierarchy, and assistive technology compatibility.
*   **Tailwind CSS System:** Engineered via a custom utility design token system, prioritizing fluid responsive layouts, intentional typographic asymmetry, and luxury editorial spacing profiles.
*   **Vanilla JavaScript (ES6+):** (In active development) Light, performant architecture decoupled from heavy frameworks to preserve lightning-fast rendering metrics.

---

## ✨ Advanced Engineering Features

### 📐 Asymmetric Layout & Typography Engine
*   **Curated Viewport Rhythm:** Replaced traditional, boxed grid constraints with a high-fashion, scattered image collage framework utilizing fluid aspect ratios, CSS translations, and hardware-accelerated micro-interactions (`scale-103`, dynamic rotations).
*   **Intentional Editorial Spacing:** Features an integrated typography scale anchoring serif titles (`font-serif tracking-tight`) to premium responsive identity elements via carefully balanced asymmetric padding barriers (`md:mt-8 md:mb-14`).

### ⚡ Media Optimization & Core Web Vitals
*   **Next-Gen Pipelines:** 100% powered by raw `.webp` image assets utilizing native browser decoding hints (`decoding="async"`) to maximize runtime performance.
*   **Critical-Path Priority Painting:** Implements explicit asset priority routing (`fetchpriority="high"`) on top-of-fold cinematic mastheads to completely eradicate Layout Shifts (CLS) and maximize Largest Contentful Paint (LCP) efficiency.

### ♿ Deep Accessibility Layer (a11y)
*   **Assistive Anchors:** Fully compliant semantic landmark containers (`section`, `aria-label`) paired with automated contextual link descriptions (`aria-labelledby`).
*   **Keyboard Navigation Ready:** Engineered with responsive focus-indicator rings (`focus-visible:ring-accent`) and native offset spacing guarantees to maintain strict WCAG accessibility patterns for non-mouse users.
