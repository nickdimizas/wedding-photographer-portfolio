# Stratos Zografos | Fine Art & Architectural Portfolio

A premium, high-end editorial portfolio application built for Athens-based photographer Stratos Zografos. This platform is meticulously engineered to bridge the gap between high-resolution media assets and elite web performance, offering an immersive boutique gallery experience.

---

## 🚀 Live Preview

- 🌐 **Live Link:** https://wedding-photographer-portfolio.vercel.app

---

## 🛠 Architectural Tech Stack

- **Semantic HTML5:** Engineered for rigorous SEO crawlability, document hierarchy, and assistive accessibility milestone tracking.
- **Tailwind CSS (v4):** Built via a utility design token system prioritizing fluid responsive layouts, intentional typographic asymmetry, and luxury editorial spacing.
- **Vanilla JavaScript (ES6+):** Light, ultra-performant frameworkless architecture designed to preserve native rendering speeds and seamless execution.

---

## ✨ Engineering Features & Optimization

### 📐 Asymmetric Layout & Editorial Typography

- **Curated Viewport Rhythm:** Replaced rigid, boxed grid constraints with a high-fashion, scattered image collage framework utilizing fluid aspect ratios and hardware-accelerated transitions.
- **Editorial Spacing:** Features an integrated typography scale anchoring serif text with clean typographic breathing room.

### ⚡ Media Optimization & Core Web Vitals

- **Next-Gen Asset Pipelines:** Powered entirely by `.webp` image assets utilizing native browser decoding hints (`decoding="async"`) to maximize speeds.
- **LCP & CLS Management:** Implements asset priority routing (`fetchpriority="high"`) on above-the-fold cinematic mastheads to completely eradicate Cumulative Layout Shift (CLS).

### ♿ Accessibility Layer (a11y)

- **WCAG Compliant:** Semantic landmark containers paired with responsive keyboard navigation focus-indicator rings (`focus-visible:ring-2`) to guarantee accessibility for all users.
