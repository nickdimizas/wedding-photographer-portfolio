# Stratos Zografos | Professional Photography Portfolio

A high-end, responsive portfolio website for Athens-based photographer Stratos Zografos, focusing on wedding, architecture, and editorial storytelling.

## 🛠 Tech Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **Tailwind CSS**: Modern utility-first styling for a bespoke, luxury feel.
- **JavaScript**: (Upcoming) For gallery filtering and smooth interactions.

## ✨ Key Features

- **Mobile-First Design**: Optimized for seamless viewing on all devices.
- **Bespoke UI**: Custom transition timings (200ms-500ms) for a cinematic experience.
- **Accessibility**: ARIA-compliant forms and keyboard-navigable elements.
- **Optimized Assets**: Next-gen image formats (.webp) for high-performance loading.
